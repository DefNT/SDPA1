# Car Builder Pattern Project

Repo demonstrating the Builder Design Pattern using a Car manufacturing example. It shows how to build complex objects step-by-step using method chaining.

## Project Structure
* **`Car.java`** — The main product object.
* **`CarBuilder.java`** — Interface declaring the step-by-step build methods.
* **`SportsCarBuilder.java`** & **`SUVCarBuilder.java`** — Concrete builders for different car models.
* **`CarDirector.java`** — Handles standard build.
* **`Main.java`** — Demo.

## How to Run

### In IntelliJ IDEA / Eclipse
1. Open the project in your IDE.
2. Run `Main.java`.
